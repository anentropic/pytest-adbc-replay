<objective>
Implement the `cassette_differentiator_keys` feature so that ADBC Foundry drivers
sharing a single Python module (`adbc_driver_manager.dbapi`) get distinct cassette
subdirectory paths based on configurable db_kwargs values.

Purpose: Without this, all Foundry drivers (MySQL, PostgreSQL, Databricks) would
write cassettes to the same `adbc_driver_manager.dbapi/` subdirectory, causing
collisions. The differentiator appends kwarg values (e.g. `driver=mysql`) as extra
path segments.

Output: Working cassette_differentiator_keys ini key, threaded through all three
connection paths, with unit tests.
</objective>
