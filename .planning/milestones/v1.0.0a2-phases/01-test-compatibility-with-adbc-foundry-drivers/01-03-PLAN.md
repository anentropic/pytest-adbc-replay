       - `pytest_plugins = ["pytester"]` (needed for pytester fixture)
       - A module-level skip check: `pytest.importorskip("testcontainers")` or use `@pytest.fixture` with skip logic
       - A `mysql_container` session-scoped fixture that:
         - Skips if `testcontainers` is not installed
         - Skips if Docker is not available (check `shutil.which("docker")` or catch container start error)
         - Starts a `MySqlContainer` from `testcontainers.mysql`
         - Yields the container with connection details
         - Stops the container on teardown
       - A `dbc_mysql_available` session-scoped fixture that:
         - Checks if `dbc` CLI is installed (`shutil.which("dbc")`)
         - Checks if the MySQL Foundry driver is available (try `import adbc_driver_manager.dbapi` and check if connecting with `driver="mysql"` is possible, or check for the driver binary)
         - Skips the test if either is unavailable
       - A `mysql_dsn` fixture that extracts the MySQL DSN/URI from the container for use in ADBC connect kwargs

    3. Create `tests/integration/test_foundry_mysql.py` with pytester-based tests:

       **Test A: Record-then-replay via wrap() with Foundry MySQL**
       - pytester.makepyfile creates a test that:
         - Uses `adbc_replay.wrap("adbc_driver_manager.dbapi", db_kwargs={"driver": "mysql", "uri": dsn}, request=request)`
         - Runs a simple query (e.g. `SELECT 1 AS answer`) via cursor
         - Asserts the result
       - Record pass: `pytester.runpytest("--adbc-record=once", "-v")`
       - Replay pass: `pytester.runpytest("-v")`
       - Assert both pass

       **Test B: Record-then-replay via auto-patch with Foundry MySQL**
       - pytester.makeini with `adbc_auto_patch = adbc_driver_manager.dbapi`
       - pytester.makepyfile creates a test with `@pytest.mark.adbc_cassette` that:
         - Calls `adbc_driver_manager.dbapi.connect(driver="mysql", uri=dsn)`
         - Runs a simple query
         - Asserts the result
       - Record pass then replay pass
       - Assert both pass

       **Test C: Cassette path differentiation verification**
       - After recording, verify the cassette files are stored under a path containing the `mysql` differentiator segment
       - Check: `cassettes/.../adbc_driver_manager.dbapi/mysql/` exists and contains cassette files

       IMPORTANT: These tests need access to the real MySQL container. The pytester subprocess needs the DSN passed in. Options:
       - Set an environment variable with the DSN before calling `pytester.runpytest()`
       - Use `pytester.makeconftest()` to inject the DSN as a fixture
       - The simplest approach: use `monkeypatch.setenv()` or write the DSN directly into the test file via f-string in `pytester.makepyfile()`

       Mark all integration tests with `@pytest.mark.integration` and add a custom marker registration.

       For skip conditions, use a pattern like:
       ```python
       pytestmark = [
           pytest.mark.integration,
           pytest.mark.skipif(
               not shutil.which("dbc"),
               reason="dbc CLI not installed"
           ),
           pytest.mark.skipif(
               not shutil.which("docker"),
               reason="Docker not available"
           ),
       ]
       ```
